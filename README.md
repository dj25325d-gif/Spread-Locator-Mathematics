## 🌟 Project Overview

Spread Locator is an end-to-end statistical analysis project developed
in Python to analyze customer transaction behaviour for an e-commerce
platform. It demonstrates statistical theory, practical implementation,
visualization, probability modelling, and business insights.

-   Apply probability distributions
-   Analyse transaction behaviour
-   Evaluate normality
-   Perform statistical transformations
-   Generate business insights

## 🧩 Project Scenario

An e-commerce platform wants to understand customer purchase behaviour
by analysing transaction amounts and transaction frequency using
statistical distributions.
